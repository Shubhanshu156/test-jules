# Webflow Workflow App - Frontend

This directory contains the frontend for the Webflow Workflow App. It's a React and TypeScript application built with Vite, designed to be embedded as a Webflow Designer App panel.

## Getting Started

### Prerequisites

- Node.js (v18 or later recommended)
- npm

### Installation

1.  Navigate to the frontend directory:
    ```bash
    cd AICodeReviewer/frontend
    ```
2.  Install the dependencies:
    ```bash
    npm install
    ```

### Running the Development Server

To start the Vite development server, run:
```bash
npm run dev
```

The app will be available at `http://localhost:5173` (or another port if 5173 is busy).
